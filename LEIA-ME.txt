PÁSSARO REWARDS V7

Novidades:
- Cada troféu concluído libera uma caixa de presente.
- Missões diárias também geram presente extra.
- Presentes podem dar moedas, chave, vida, escudo, tartaruga ou ímã.
- Novos mapas:
  - Mapa do Amor
  - Floresta
  - Estádio de Futebol
  - Noite Artística
  - Mapa Espacial
- Mapa Espacial só pode ser usado se tiver o Pássaro Astronauta.
- Novos pássaros:
  - Pássaro Astronauta
  - Pássaro Apaixonado

Para atualizar no GitHub:
1. Extraia o ZIP.
2. Envie os arquivos para o mesmo repositório.
3. Clique em Commit changes.
4. Aguarde o GitHub Pages atualizar.


CORREÇÃO SCROLL:
- Menus longos agora podem ser arrastados/rolados no celular.
- Loja, troféus e missões ganharam área de rolagem.
